# Grade 2 Module 3: concept-ID lesson assessments

Each supplied lesson has a standalone concept JSON and one assessment named
`<concept_id>.assessment_card.json`. Use `module_index.json` for paths and hashes.
All question, rubric, hint, feedback, follow-up and worked-answer content is
preserved. The former assessment bundles and duplicates were removed; their
history is available in Git. Concept sources and validation reports are retained.
Repository paths are relative to repository root; ZIP paths are relative to
its extracted folder. Cards remain drafts requiring educational review and
script-agent integration testing.

Only Lesson 1 has a supplied concept. Lessons 2–21 remain pending.
