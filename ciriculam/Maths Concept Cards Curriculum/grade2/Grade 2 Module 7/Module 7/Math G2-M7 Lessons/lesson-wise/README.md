# Grade 2 Module 7: complete lesson pairs

Lessons 1–26 each have one concept JSON and one full assessment JSON named
`<concept_id>.assessment_card.json`. The existing ten assessments are unchanged;
sixteen missing assessments were added. Every assessment has easy, medium and
hard questions, two follow-ups, four local rubrics, fifteen hints and five
question guidance records with feedback, worked answers and bounded routes.

Use `module_index.json` to select the two inputs and verify linked ID/version
and hashes. Repository paths are relative to repository root. Module ZIP paths
are relative to its extracted directory. The original concept collection is
retained under `../legacy/module-wide/` for provenance; each concept object is
preserved exactly. No assessment bundle or duplicate draft is created.

All cards remain drafts requiring human educational review. Actual script-agent
integration is untested. Open easy answers in Lessons 17, 18 and 24 require
semantic grading against their source rubrics and partial criteria. Lengths in
Lesson 18 are approximate; numeric codes label unit choices. Numeric answers
cannot verify physical measuring, ruler/graph construction or spoken reasoning.
Source review flags remain preserved.
