# Lesson player — Amna / Track B

Public API: `LessonPlayer` from this folder's `index.ts`.

Opt-in review screen for the selected script-agent draft, using the public voice feature. It follows only `delivery_policy.main_path`, pauses at reflections and questions, and shows visual directions as captions. No avatar, widget, answer grading, auth replacement or event writes. Setup and limitations: repository `voice_service/README.md`.
